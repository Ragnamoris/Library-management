\# Библиотека (library\_management)



\## Предметная область



Библиотека располагает фондом книг, который постоянно пополняется. Книги издаются различными

издательствами. Читатель может взять на абонемент не более пяти книг одновременно на срок до

двадцати дней.



Необходимо организовать учёт издательств, книг, читателей и выдач, чтобы получать сведения о

наличии книг, контролировать их возврат и отслеживать книги, находящиеся у читателей.



\## Правила предметной области



\- одно издательство может выпускать несколько книг;

\- каждая книга относится к одному издательству;

\- одна книга может выдаваться читателям много раз;

\- каждая выдача относится к одной книге;

\- один читатель может одновременно взять несколько книг;

\- каждая выдача оформляется для одного читателя;

\- книга может находиться в фонде, но ещё ни разу не выдаваться;

\- каждая выдача должна относиться к существующей книге и читателю.



\## Дополнительные ограничения



\- одновременно у читателя на руках не более 5 книг;

\- срок пользования книгой — 20 дней;

\- книга, находящаяся на руках, не может быть выдана повторно;

\- просрочка определяется по дате возврата относительно плановой даты.



\## Ключевые сущности



\### Издательство (Publisher)



| свойство | тип данных |

|---|---|

| id издательства (UUID) | Uuid |

| наименование издательства (уникальное) | String |

| адрес | String |

| created\_at | UtcDateTime |

| updated\_at | Option<UtcDateTime> |

| deleted\_at | Option<UtcDateTime> |



\### Книга (Book)



| свойство | тип данных |

|---|---|

| id книги (UUID) | Uuid |

| id издательства (UUID, FK) | Uuid |

| название | String |

| автор | String |

| год издания | i32 |

| инвентарный номер (уникальный) | String |

| created\_at | UtcDateTime |

| updated\_at | Option<UtcDateTime> |

| deleted\_at | Option<UtcDateTime> |



\### Читатель (Reader)



| свойство | тип данных |

|---|---|

| id читателя (UUID) | Uuid |

| ФИО | String |

| телефон (уникальный) | String |

| номер читательского билета (уникальный) | String |

| created\_at | UtcDateTime |

| updated\_at | Option<UtcDateTime> |

| deleted\_at | Option<UtcDateTime> |



\### Выдача (Loan)



| свойство | тип данных |

|---|---|

| id выдачи (UUID) | Uuid |

| id книги (UUID, FK) | Uuid |

| id читателя (UUID, FK) | Uuid |

| дата выдачи | UtcDateTime |

| плановая дата возврата | UtcDateTime |

| фактическая дата возврата | Option<UtcDateTime> |

| created\_at | UtcDateTime |

| updated\_at | Option<UtcDateTime> |

| deleted\_at | Option<UtcDateTime> |



\## Связи



\- publishers 1 : M books

\- books 1 : M loans

\- readers 1 : M loans



\## Стек



Rust, SQLite, sqlx-cli (миграции), async-sqlite / rusqlite (доступ к данным), smol (асинхронный рантайм), uuid, time.
